# Budget Josh

PWA personnelle de budgets et d'objectifs, en français, pensée d'abord pour le téléphone (PHP, MySQL, JavaScript natif).

- Contexte, règles et architecture : `CONTEXTE.md`
- État et lot en cours : `SUIVI.md`

Tests : démarrer le serveur local sur `http://127.0.0.1:8080`, puis `npx playwright test`.
