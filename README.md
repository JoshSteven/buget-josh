# Budget Josh — version 2

Cette version reprend la méthode du fichier Excel : apports personnels ou liés aux projets (TEDxOuaga, CAFDO, YELEKO), dîme automatique à 10 %, priorités non obligatoires, catégorie **Petits chiens**, dépenses prévues ou réalisées et objectifs annuels à dérouler par mois.

Téléversez le contenu du dossier sur votre sous-domaine o2switch en HTTPS. Installez ensuite le site depuis Chrome sur Android via **Ajouter à l'écran d'accueil**.

Les données sont locales à l'appareil dans cette version. La prochaine évolution pourra être une connexion sécurisée avec base de données afin de synchroniser téléphone et ordinateur.
